# Insurance Brokerage Analysis: Weekly Branch Dashboard

Weekly branch performance dashboard for insurance brokerage data (New, Cross-Sell, Renewal) built with Excel, Tableau, Power BI and MySQL.

## Objective
Build a weekly dashboard for the corporate team and branch heads to review New, Cross-Sell and Renewal performance against budget.

## Tools Used
Excel | Tableau | Power BI (in progress) | MySQL (in progress)

## Data
Insurance brokerage data covering Opportunity, Brokerage, Fees, Individual Budgets, Invoice and Meetings. The project uses only the provided datasets.

## What I Did
- Modelled the datasets and built the KPIs for the weekly branch review
- Built an interactive dashboard in Excel
- Rebuilt the same dashboard in Tableau
- Power BI and MySQL versions are in progress

## Key Insights
- **Renewals beat their target:** Placed achievement reached 150.2% of target (18.5M against 12.3M), with 66.9% invoiced.
- **Cross-Sell is partly there:** 64.9% of target placed, but only 14.2% invoiced.
- **New business is furthest behind:** only 18.0% of target placed and 2.9% invoiced.
- **Placing is ahead of invoicing:** Overall, 67.4% of target was placed but only 23.5% invoiced, so a large share of placed business is still to be invoiced.
- **Pipeline is early stage:** 49 opportunities, 44 of them open, and 86% of the 6.9M pipeline revenue sits in the Qualify Opportunity stage.
- **Invoice volume:** Renewals account for 97 of 204 invoices, and Divya Dhingra handled the most invoices (63).
- **Meetings:** 34 meetings logged, 31 of them in 2020, with Abhinav Shivam leading with 7.
